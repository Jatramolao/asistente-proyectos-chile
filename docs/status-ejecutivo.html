Tecnología y arquitectura

Un monolito modular, trazable y preparado para el piloto

La aplicación separa experiencia, reglas y datos para que los requisitos oficiales puedan actualizarse sin rehacer el producto.

Flujo técnico principal Node.js 24 · Next.js App Router
  1. 01 · Experiencia Interfaz web Next.js 16, React 19 y Tailwind CSS 4.
  2. 02 · Aplicación Rutas y acciones App Router, Server Actions y API de autenticación.
  3. 03 · Reglas Servicios y dominio Extracción conservadora, matching, checklists y Zod.
  4. 04 · Persistencia Datos versionados SQLite para usuarios y proyectos; JSON para convocatorias.

Brechas y controles

Cuatro asuntos condicionan el siguiente ciclo

P0

Confianza y vigencia del catálogo

La revisión es manual y cuatro registros están vencidos. Se debe diferenciar claramente fecha de revisión, cobertura y disponibilidad.

P1

Cobertura de la orientación contextual

El piloto cubre tres requisitos revisados de All In. La ampliación debe mantener trazabilidad editorial y control por versión.

P1

Continuidad y respaldos

La aplicación usa SQLite en un volumen persistente y una réplica. Los respaldos siguen siendo manuales.

P1

Validación con usuarios reales

Falta medir si una persona sin experiencia comprende la recomendación, avanza y distingue orientación de evaluación.
